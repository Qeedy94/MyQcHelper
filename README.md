# Punta Destroyer

Android-приложение для контроля качества моделей обуви: загружает заказы из Excel, хранит результаты проверки, связывает модели с макетами и дополнительными фотографиями, показывает календарь приёмок и проверяет обновления.

## Стек и архитектура

- Kotlin 2.2.10, Jetpack Compose и Material 3 (Compose BOM 2026.02.01).
- Минимальная версия Android: API 26; target/compile SDK: 37.
- Apache POI 5.2.3 читает `.xlsx`/`.xls`; Gson 2.10.1 сохраняет список заказов; Coil 3.2.0 отображает изображения.
- `MainActivity.kt` содержит Compose-навигацию, экраны и SAF-операции.
- `ModelProgressStore.kt` изолирует прогресс модели по идентификатору заказа и артикулу.
- `TouchProtection.kt`, `ReworkReasonPicker.kt` и `OrderStatsRing.kt` содержат переиспользуемые UI-компоненты.
- `UpdateManager.kt` проверяет и загружает обновления.

Тяжёлые операции с Excel, SAF, JSON и загрузкой обновлений выполняются на `Dispatchers.IO`; Compose-состояние изменяется на основном потоке.

## Данные и хранение

Используется существующий файл SharedPreferences `QC_PREFS`:

- `saved_orders` — JSON со списком заказов;
- `model|…` — прогресс конкретной модели в конкретном заказе; старые ключи вида `ARTICLE_decision` сохраняются для совместимости и однократно копируются в новые;
- `rework_reasons` — существующий список причин доработки;
- `images_folder_uri` — URI выбранной SAF-папки;
- `theme_mode`, `touch_protection_mode`, `status_vibration_enabled` — пользовательские настройки.

При повреждении `saved_orders` приложение не подменяет данные пустым списком и сохраняет исходную строку один раз в `saved_orders_corrupt_backup` для диагностики. Резервное копирование включает `QC_PREFS.xml`. Постоянные SAF-разрешения не переносятся между устройствами, поэтому после восстановления папку нужно выбрать повторно.

## Excel и структура папок

Правила разбора не должны изменяться без проверки реальных производственных файлов. Название файла является идентификатором заказа; фабрика, формат, поставка и внутренняя папка формируются существующими правилами в `parseExcel`. В первой таблице читаются установленные столбцы, включая артикул (C), дату (P) и комментарии (обнаруженный заголовок либо T). Для каждого заказа в выбранной SAF-папке создаётся внутренняя папка `order.internalFolderName`.

Макеты моделей распознаются по нормализованному имени файла. Файлы `extra_…` являются дополнительными фотографиями и не заменяют основной макет. Не меняйте имена файлов, папок и URI при UI-изменениях.

## Обновления

`UpdateManager` получает список ZIP-файлов из настроенного Object Storage, выбирает более новую версию `Punta_destroyer_v*.zip`, скачивает архив и извлекает APK в кэш. Ошибка сети отображается отдельно от состояния «последняя версия». Установка выполняется системным Android-установщиком.

## Сборка и проверки

Нужны JDK 17 и Android SDK с platform 37.

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

В Windows без настроенного `JAVA_HOME` укажите JDK, входящий в Android Studio. Инструментальный тест запускается отдельно на устройстве или эмуляторе:

```bash
./gradlew connectedDebugAndroidTest
```

CI выполняет unit-тесты, Android Lint и debug-сборку. Реальные SAF-права, камеру, полноэкранное масштабирование и производственные Excel-файлы также необходимо проверять на устройстве.
